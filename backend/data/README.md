# data

Precomputed source data served by the backend for example sites.

| File | What it does |
|------|--------------|
| `grace_huaral.json` | GRACE/GRACE-FO mascon CRI v4 monthly series (cm water equivalent), Huaral; from `tools/grace_point.py` |
| `projection_huaral.json` | NEX-GDDP-CMIP6 v2.0 ensemble change ~2040 vs 1995-2014 (temperature, rain), Huaral; from `tools/nex_gddp_point.py` |
