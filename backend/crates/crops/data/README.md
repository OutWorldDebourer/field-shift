# data/

Verified seed knowledge base: one JSON crop record per file (`pea.json`, `common_bean.json`, `alfalfa.json`, `quinoa.json`, `maize.json`, `cotton.json`, `lettuce.json`, `potato.json`, `sweet_potato.json`, `tomato.json`, `onion.json`, `asparagus.json`, `mandarin.json`, `avocado.json`, `grape.json`, `mango.json`, `strawberry.json`, `pineapple.json`), embedded in the binary by `src/seed.rs`. Each trait is `{value, unit, citation, note?}` or `{gap}`; a value without a source is a gap, never a guess. Researched 2026-11-14 with web search; FAO Land & Water crop pages were offline (404), so FAO-56, the FAO Training Manual 3 and Ecocrop were used instead.
