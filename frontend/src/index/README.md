# index

- `main.ts` — renders the page, scroll → globe progress, sunrise/daylight veil, dataset leader lines.
- `sections.ts` — markup of the top bar, six sections, footer and corner instruments.
- `sky.ts` — fixed sky: live globe or the illustrative still, reticle, ground labels, instruments.
- `preview.ts` — dashboard preview panel (reuses the app's dashboard markup with demo data).
- `index.css` — page styles.
