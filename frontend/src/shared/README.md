# shared

- `tokens.css` — fonts (@font-face), colour/type tokens, base elements, focus, selection, reduced motion.
- `components.css` — glass, buttons, EN|ES switch, instruments, reticle, badges, data row, chat bubbles, photo tiles, backdrop.
- `charts.css` — season chart, NDVI chart, calendar strip, dot scores.
- `contract.ts` — HTTP contract with the backend (two optional frontend additions are marked).
- `strings.ts` — every UI string in EN and ES.
- `i18n.ts` — language state (`?lang=`, localStorage), `t()`, `pick()`, number/date formatting.
- `langswitch.ts` — EN | ES switch markup and wiring.
- `api.ts` — typed client with timeouts and the offline demo fallback (iteration 3: PDFs in the "photos" field with their real name, `submitIntake`, `exampleIntake`).
- `datarow.ts` — the data row (icon, label, value, verdict, source · date, badge, sparkline).
- `evidence.ts` — reads the package without assuming which readings exist (key rows, normal period, short labels, derived headline).
- `charts.ts` — SVG charts and the 12-month strip.
- `phone.css` — phone fixes found on iPhone (WebKit) and Android (Chromium) profiles: no sideways drift (root overflow clip), opaque fixed headers, the phone mock's value and chip on two lines, opaque index cards over the globe labels, a two-line app footer, notch-safe padding in landscape.
- `charthover.ts` — pointer and keyboard read-out for SVG charts: snaps to the nearest point, guide line, ring and a label with date and values; ←/→, Home/End, Esc; keyboard moves announced.
- `backdrop.ts` — field-from-above plate (backend Sentinel-2 snapshot, else EOX tiles) with outline and reticle.
- `phone.ts` — the hero's glass phone.
- `geo.ts` — area in ha, centroid, bbox helpers.
- `icons.ts` — line icon set.
- `dom.ts` — escaping, element helpers, toast.
- `demo/` — bundled Huaral demo dataset.
- `glossary.ts` — bundled bilingual glossary (fallback for GET /api/glossary, same keys) and reading id → term.
- `glosspanel.ts`, `glosspanel.css` — ⓘ "What does it mean?" buttons and the glossary side panel (enabled per page).
- `pests.ts` — pest names in the UI language (`name_bi` from the backend, else a local map); `ownCropPest` keeps reference and other crops' pests out of alerts and topics.
- `viewctx.ts`, `askbtn.css` — what the farmer is looking at (tab + focused card), sent with every chat turn; the "Ask about this" button.
- `localize.ts` — Spanish for English fragments inside backend units and source lines ("vs normal", "generations", …).
