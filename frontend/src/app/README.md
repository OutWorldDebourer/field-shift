# app

- `main.ts` — routing by query string: field selection or workspace; loading/error states.
- `state.ts` — tiny store (analysis, view, open section) and URL sync.
- `app.css` — page shell, loading and error states.
- `field/` — field selection; `map/` — Leaflet loader and layers; `workspace/` — chat, sections, dashboard, rotation, export.
