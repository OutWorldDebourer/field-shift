# workspace

- `workspace.ts` — shell (top bar, tabs, backdrop, footer notice, phone bottom sheet) and event wiring.
- `chat.ts` — chat log, photo tiles with reticle, composer (≤10 photos, drag and drop, camera), crop inputs with suggestions.
- `photos.ts` — downscale to ≤1600 px JPEG.
- `sections.ts` — section column, phone round buttons, section bodies and progress rings.
- `dashboard.ts` — dashboard markup and the live map with the honest-scale layer switch.
- `alerts.ts` — alerts from the evidence (or derived from readings).
- `rotation.ts` — pre-diagnosis card and strategy comparison (practices for perennials).
- `export.ts` — technical sheet, CSV, share link.
- `workspace.css`, `dashboard.css` — styles.
